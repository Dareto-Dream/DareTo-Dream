### About Me
I’m **DeltaVortex**, a developer and systems engineer behind **DeltaVDevs**.  
I build across software, hardware, and AI — focused on creating systems that feel responsive, intentional, and human.

- **Focus Areas**
  - AI systems and automation pipelines  
  - Game development (rhythm + narrative systems)  
  - Embedded systems (ESP32, Raspberry Pi, Jetson)  
  - Custom tooling and compilers  

- **Philosophy**
  - Systems should be **functional first, expressive second**  
  - Good design reduces friction, not just adds style  
  - If something doesn’t exist, build it
